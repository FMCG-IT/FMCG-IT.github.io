# Manual ticket submission

1. In Supabase SQL Editor run 20261115_department_roles.sql if the department role update was not applied. If needed, redeploy the included manage-officers Edge Function for department role management.
2. Run 20261115_employee_portal.sql if it has not already been applied.
3. Run 20261115_manual_employee_tickets.sql.
4. Upload src and index.html to GitHub. On the sign-in page, choose Submit a ticket. Microsoft configuration is not needed.
5. Make sure each department has a Department manager and an active officer covering the submitted office. The Overall IT Manager can see all pending requests.

The submission page is public. Name and email are self-reported, and the form does not verify company affiliation. Each submission returns a private tracking link. Keep it private. The tracking page displays status and public updates, and does not reveal the email address.
