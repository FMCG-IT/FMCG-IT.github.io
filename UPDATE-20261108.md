# Team and ticket list update

This package updates an existing IT Desk installation. Do not rerun first-manager.sql or recreate your database.

1. In Supabase SQL Editor, run supabase/migrations/20261108_team_management.sql.
2. Upload the src folder from this update into the root of FMCG-IT/FMCG-IT.github.io and commit to main. These files replace the corresponding files. The existing GitHub Actions workflow publishes the change.
3. When Actions is green, refresh IT Desk. IT team contains section member counts and member edit/delete controls for managers. Deleting removes app access and transfers all tickets to the selected replacement; history remains. It does not delete a Supabase Auth account.
4. Existing Network/Hardware staff appear in Infrastructure. Existing Software/System/IT Support staff appear in Software/System. Edit a member's section to move them into SAP.
5. Old cached tabs should be reloaded. Older app versions must be updated before attempting to add officers because the new API accepts only the three explicit sections.

Overview section cards continue to show active ticket counts; IT team section cards show member counts.
